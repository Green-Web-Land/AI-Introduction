# Curriculum

[Course home](README.md)

Adult workplace beginners; no assumed employer, occupation or technical background. Bring paper or a local editor. Basic arithmetic helps; calculations and answer reasoning are supplied. Every activity is fictional and offline.

| Lesson | Intended outcome |
|---|---|
| [1. Choose a bounded task](lessons/01-task.md) | Define a useful output that you can check. |
| [2. Check workplace permission](lessons/02-permission.md) | Separate approved use from technical capability. |
| [3. Choose inputs that belong in the task](lessons/03-inputs.md) | Use invented material without disguising real confidential information. |
| [4. Give context without granting extra authority](lessons/04-instructions.md) | Write a draft request with a checkable boundary. |
| [5. Check a summary against its source](lessons/05-summary.md) | Find unsupported statements and repair them. |
| [6. Draft communication without making promises](lessons/06-message.md) | Write a clear draft that remains within the facts. |
| [7. Verify numbers and prioritisation](lessons/07-table.md) | Check arithmetic separately from the choice of what to do first. |
| [8. Separate a draft from an action](lessons/08-actions.md) | Check the exact action and authority before changing anything. |
| [9. Make an accountable handoff](lessons/09-handoff.md) | Report evidence, uncertainty and the next step without pretending receipt. |
| [10. Build a repeatable workflow](lessons/10-future.md) | Evaluate useful assistance without promising employment outcomes. |

## Method and completion

Each lesson contains an objective, explanation, worked example, supplied practice, reasoned answer and transfer task. Suggested 20–35-minute sessions are adjustable and untested. Use breaks, spoken explanations or written responses as useful.

Lessons 5–6 and 9 share a fictional packet. Version 1 of K is not started; version 2 is in progress but not complete. The workload table is a separate example, not data about those individual items. Keep these contexts distinct.

The final portfolio includes a task brief, permission decision, input choice, repaired summary, calculation, action boundary and handoff. Use [feedback guidance](FACILITATOR-GUIDE.md) to identify what to revisit. Completion does not establish workplace competence, security clearance, professional certification or permission to use a real tool.
