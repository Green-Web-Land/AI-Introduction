# 3. Choose inputs that belong in the task

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

## Objective

Use invented material without disguising real confidential information.

## Explanation

For this course, use only the supplied fictional packet and data. Do not paste real customer messages, personnel records, passwords, internal contracts or private notes. Removing names alone does not settle confidentiality or permission.

A prompt such as “do not reveal this” is not a technical privacy safeguard. A policy, provider terms, access controls and actual data handling are different things. This course establishes none of them for a live service.

## Worked example

A worker needs practice writing a delay update. They could upload a real complaint with names removed, or use the invented delayed-item note in Lesson 5. Use the invented note. It teaches the writing task without importing hidden details from a real case.

If real material was accidentally shared, follow the workplace incident route promptly. Do not make further copies to demonstrate the mistake or claim deletion from a prompt alone.

## Practice

Choose the safer input for this exercise: a real complaint with an account number removed; an invented three-line note; or a screenshot of an internal spreadsheet. Explain why “only a screenshot” is not an exemption.

## Answer and reasoning

Try the practice before reading this section.

Use the invented note. Screenshots can still contain confidential data, visible identifiers or contextual details. The course does not need real evidence. Replacing the example is different from asserting a document has been fully anonymised.

## Transfer task

Write a wholly invented note about a delivery date that is not confirmed. It must contain no real person, organisation or disguised event. Example: “Item K is delayed; a date is requested but not confirmed.” State which facts are missing instead of filling them with details from an actual case.
