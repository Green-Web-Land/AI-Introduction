# 1. Choose a bounded task

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

## Objective

Define a useful output that you can check.

## Explanation

Start with the work, not the tool. Name the audience, input, output and the decision that remains yours. Generative AI can help draft or reorganise content, but a fluent reply may be wrong. The [Cyber Centre guidance](../SOURCES.md) supports checking outputs and considering sensitive inputs; it does not validate this course.

A small task might be preparing a draft summary from supplied notes. “Manage the whole service desk” hides many decisions and actions. Use a checklist, calculation or manual approach when it already fits the task.

## Worked example

Fictional brief: “Prepare three bullets for an internal review from the packet in Lesson 5. Separate confirmed facts from open questions. Do not send messages or change records.”

Success means each bullet matches the packet, uncertainty is visible and no action has been taken. It does not mean the service issue has been resolved.

## Practice

Improve this vague task: “Use AI to improve operations.” Specify one draft output, what evidence it uses, how you will check it and one action outside its scope.

## Answer and reasoning

Try the practice before reading this section.

One answer: “Draft a status summary from the supplied fictional notes; compare every factual statement with the notes; leave external sending out of scope.” Other bounded outputs can work. A shorter task description is not enough unless it makes checking and responsibility clear.

## Transfer task

A colleague asks for a list of questions for tomorrow's review. Define the task without granting permission to book meetings or contact anyone. An acceptable brief asks for a draft question list using the supplied facts, with missing details marked. Explain why a question list is a different deliverable from running the review.
