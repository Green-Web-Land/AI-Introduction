# Glossary

[Course home](README.md)

| Term | Meaning here |
|---|---|
| Generative AI | AI producing content such as text, images or code; output may need correction. |
| Bounded task | A task with clear inputs, output and limits. |
| Prompt | Input or instructions to a system; not an implemented permission or privacy control. |
| Source packet | The supplied fictional notes against which claims are checked. |
| Confirmed | Supported by the stated evidence in the exercise, not merely expected. |
| Draft | Prepared material awaiting whatever review or action the real process requires. |
| Authority | Permission for a particular use or action from the applicable responsible process. |
| Confidential | Information whose use or disclosure is restricted in its context. |
| Safeguard | A measure intended to reduce risk; it needs implementation and checking. |
| Weighted average | An average that accounts for the relevant counts or weights. |
| Priority | A choice about order based on stated criteria and context, not arithmetic alone. |
| Handoff | Information passed for another person's next action; preparation is not receipt. |
| Acknowledgement | Confirmation from the recipient, distinct from sending. |
| Version | An identified state of content or data. |
| Verification | Checking a claim or result against relevant evidence. |
| Scenario | A conditional possibility, not a certain forecast. |
