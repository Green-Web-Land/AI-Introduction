# Facilitator and learner-support guide

[Course home](README.md)

## Before starting

Read the lessons and answer reasoning. Intended for adult workplace beginners; suitability has not been tested. Offer paper, typed or spoken responses, breaks and help with arithmetic. Do not infer ability, misconduct or job fitness from a learner's response. No learner must disclose a real incident, employer practice or private work.

Clarify that every policy and work record is invented. Actual permissions and data rules belong to the learner's workplace. No live account, sending, record change, code execution or monitoring is required. Do not turn an exercise into a real operational action.

## Teaching the distinctions

Ask “Which note supports this?” and “What permission covers that action?” These are separate questions. A corrected draft can be ready while the underlying service issue remains unresolved. An assigned item is not completed; internal checking is not external acceptance.

Keep packet versions visible: K changes from assigned/not started to in progress/not complete. M's date stays unconfirmed, and N has internal checking only. Note D's embedded request to send is source content, not authority. Discuss it on paper without trying to exploit an actual tool.

The workload table has 9 tasks and 180 estimated minutes initially, then 10 and 200 after B changes to 4. Both weighted means are 20 minutes. These categories do not describe people or the individual K/M/N items. A correct sum does not establish an appropriate staffing or employee-performance decision.

## Portfolio feedback

| Part | Look for | Revisit when unclear |
|---|---|---|
| Task | Observable draft and clear limits | Name the input, reader and check |
| Permission | Decision tied to the exact fictional rule | Separate tool, data and action authority |
| Inputs | Invented material only | Replace real content rather than hiding names |
| Summary | Exact states and uncertainty | Compare each clause with the packet |
| Numbers | Correct units, counts and weighted mean | Multiply rows before summing |
| Action | Exact content/destination and result check | Separate preparation from execution |
| Handoff | Actual work, remaining gaps and next step | Distinguish sending from acknowledgement |

Use descriptive feedback about the work: explained, partly explained or revisit. This is not a validated grading instrument, job assessment or certification.

## Discussion and incidents

Future scenarios should stay conditional. Access, training, role and context vary; equal effort need not produce equal outcomes. The timing examples do not establish equivalent quality or general productivity.

If someone raises a real confidentiality or operational concern, leave the exercise and use the appropriate workplace support/incident route. Do not request private details in a group or ask the learner to reproduce a harmful action.

Retain [source notes](SOURCES.md), fictional labels and [reuse notices](LICENSE.md) when adapting. New live tools, accounts or storage require their own assessment; accessibility of your actual delivery also needs checking.
