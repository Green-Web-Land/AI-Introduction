# Developer guide

[Course home](README.md)

Copy this complete folder from an approved revision, retaining lessons, images, sources and licence. Pin the revision. If distributing separately, adjust the series-home link and keep source credit. Public readers must not depend on private review links.

## Presentation

Preserve headings, practice/answer separation, alt text and image text equivalents. PNGs accompany editable SVGs. Keep tables readable or supply equivalent lists. Test your own renderer for keyboard use, zoom and assistive tools before claiming accessibility compliance. No formal accessibility certification is supplied.

No AI endpoint, learner account, form, tracker or automatic sending is implemented by these course files. Hosting services have their own behavior; this is not a claim that GitHub or a host collects no data. Added accounts, analytics, stored answers or integrations need separate assessment and disclosure.

## Protect the learning boundaries

Keep fictional examples. Do not request actual correspondence, photos, recordings or relationship histories. Do not turn exercises into automated messages, diagnosis, persuasion scores or monitoring. Preserve options to decline and stop. A safety guarantee must not be added to a generated rewrite.

Recheck dated sources when adapting. Translation and commercial reuse follow the licence; label changes and do not imply endorsement. Content checks do not establish WebAI runtime behavior, integration compatibility or clinical effectiveness.
