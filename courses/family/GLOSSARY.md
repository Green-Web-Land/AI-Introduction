# Glossary

[Course home](README.md)

| Term | Meaning here |
|---|---|
| Generative AI | Technology producing content from input; output needs checking. |
| Draft | Wording offered for review, not proof of an action. |
| Observation | What the supplied evidence actually shows. |
| Interpretation | A possible explanation, not necessarily a fact. |
| Unknown | Something the available information does not settle. |
| Boundary | A stated limit on participation, contact or use. |
| Specific agreement | Agreement to the stated activity and conditions, not every later use. |
| Privacy | Care over access to and use of personal information. |
| Placeholder | A label like [time] used instead of an actual detail. |
| Overlap | The time interval available in both supplied windows. |
| Proposal | An option still needing acceptance. |
| Independent check | Checking against facts or rules rather than trusting fluent wording. |
| Scenario | A possible future under conditions, not a guarantee. |
| Transfer task | Applying an idea to a new example. |
