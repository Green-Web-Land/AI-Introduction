# Glossary

[Course home](README.md)

| Term | Meaning here |
|---|---|
| Generative AI | Technology that produces content from input; its output needs checking. |
| Prompt | A request and its context. |
| Constraint | A limit such as available materials or time. |
| Draft | A proposed version for review, not a completed action. |
| Evidence | Information relevant to checking a specific claim. |
| Not established | Available evidence does not settle the claim. |
| Capacity | Maximum stated places, not places still available. |
| Placeholder | A label such as [time] used instead of an actual detail. |
| Independent route | A contact established separately from the message being checked. |
| Permission | Authorization for a specified use, not blanket approval. |
| Tool access | Product ability to interact with files or services, distinct from generated wording. |
| Scenario | A possible future under conditions, not a guarantee. |
| Transfer task | A new example that requires using the idea beyond copying. |
