# Developer guide

[Course home](README.md)

Copy the complete courses/retirement folder from an approved revision, including source records, pictures and licence. Pin the revision used. For standalone distribution, adjust the series-home link and retain source attribution. Do not depend on a private repository for public navigation.

## Rendering

Preserve lesson filenames, headings, exercise/answer separation, alt text and text equivalents. PNGs accompany editable SVGs. Keep tables readable or provide equivalent lists. Test your host's zoom, printing, keyboard and assistive-tool behavior before making accessibility claims. The course has no formal accessibility certification.

No account, AI endpoint, form, embedded tracker or automatic submission is supplied by these files. GitHub and other hosts have their own behavior; static content does not establish that a host collects no data. Added analytics, accounts, stored answers or external AI calls require separate assessment and disclosure. Do not send exercise answers automatically.

## Integrity and reuse

Fictional cards are teaching fixtures, not actual listings. Preserve unknowns, no-action boundaries and the scenario/forecast distinction. Do not replace examples with private learner data. Refresh dated references before substantive adaptations.

Translation and commercial reuse are permitted under the licence. Identify changes and do not imply endorsement. Developer integration testing is separate from content checks; no WebAI runtime behavior is established here.
