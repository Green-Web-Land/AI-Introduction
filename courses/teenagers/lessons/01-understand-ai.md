# Understand AI and choose a task

[Home](../README.md) · [Curriculum](../CURRICULUM.md) · [Glossary](../GLOSSARY.md)

**Objective:** Explain how an AI model differs from the application and tools around it.

A model generates or classifies an output from inputs, often using patterns learned during development. An application decides how you interact with that model and may connect it to search, storage or tools that act. A fluent answer does not prove understanding of your situation, current knowledge or permission to act.

Consider a fictional events assistant. It suggests a meeting agenda. That is a text output. It claims to have sent the agenda. That claim needs separate evidence: a sending tool, permission, and a delivery record. Even a send confirmation does not establish that someone read it.

## Practise

Sort these tasks by the simplest suitable method, and explain your choice:
1. Add a supplied list of six costs.
2. Invent three fictional event names.
3. Find the confirmed time of a real event.
4. Send invitations to real people.

Possible reasoning: a calculator handles the sum predictably; AI may help brainstorm names, but you choose; an organiser's current information is needed for the time; sending requires an authorised communication process. No one method is always best.

## Check yourself

A tool writes “I remember everything about you.” What would you need to know before relying on that statement? Check the product's actual storage and memory behaviour; the wording alone establishes neither persistent memory nor privacy.

**Transfer task:** choose a small fictional project and separate its information, creative and action steps. Name which steps could use ordinary tools and which might benefit from AI.

**Takeaway:** choose the task first. Learn enough about the application to know what it can actually do.

All situations, outputs and worked examples in this lesson are fictional teaching material. No live AI account or submission is required.
