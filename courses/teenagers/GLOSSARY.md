# Glossary

[Home](README.md)

| Term | Meaning in this course |
|---|---|
| Model | A system that produces outputs from inputs, often using patterns learned from examples. |
| Application | Software around a model, which may add storage, search or tools. |
| Prompt | Instructions or information supplied to an AI system. |
| Evidence | Information or a reproducible check that helps assess a claim. |
| Provenance | Where material came from and how it was produced or changed. |
| Verification | Checking against appropriate evidence or a reliable method. |
| Consent | Agreement to a particular use or action; not unlimited permission. |
| Data minimisation | Using only information needed for a task. |
| Bias | A pattern that can produce systematically unbalanced or unfair results. |
| Impersonation | Presenting yourself or invented material as another person. |
| Scenario | A possible future described with assumptions. |
| Principle | A guiding idea about what ought to happen. |
| Safeguard | A practical measure intended to reduce a risk. |
| Human agency | People's ability to make meaningful choices and question decisions. |

Explain one term through a fictional example. Words can have more specific meanings in law or technical practice; these are learning definitions.
