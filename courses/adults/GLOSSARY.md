# Glossary

[Home](README.md) · [Curriculum](CURRICULUM.md)

These are brief course explanations, not legal or universal technical definitions.

| Term | Meaning in this course |
|---|---|
| AI system | A computer-based system that infers outputs from inputs for a purpose. |
| Model | The computational component used to infer outputs. |
| Generative AI | AI used to produce content, such as text. |
| Application | The software interface and workflow surrounding capabilities such as a model. |
| Tool | A connected capability that may retrieve information or perform an action. |
| Prompt | Instructions and information supplied to guide a response. |
| Context | Information available for the current task; its scope varies by system. |
| Training | A process used to develop or adjust a model; different from simply receiving an answer. |
| Hallucination / confabulation | Plausible generated content that is false or unsupported. |
| Verification | Checking a result against relevant evidence or an appropriate independent method. |
| Bias | A systematic tendency that can distort results or disadvantage people; context matters. |
| Permission | Authority for a particular use or action; technical access alone does not establish it. |
| Safeguard | A measure intended to prevent, restrict, detect or help remedy an unwanted outcome. |
| Human agency | A person's ability to understand, choose, act and question outcomes. |
| Synthetic example | Invented teaching or test material, not an actual person's case. |
| Scenario | A possible sequence or future under stated assumptions, not a guaranteed prediction. |
| Pinned revision | A specific version identified by a commit or equivalent immutable identifier. |

See [sources](SOURCES.md) for supporting references and limits.
