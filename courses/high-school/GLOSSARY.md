# Glossary

[Course home](README.md)

| Term | Meaning here |
|---|---|
| AI | Systems used for tasks such as pattern recognition or generating suggestions. |
| Generative AI | AI that produces content such as text, pictures or code. |
| Prompt | Input or instructions given to an AI system; not a guarantee of behaviour. |
| Claim | A statement that can be examined for support. |
| Evidence | Relevant information used to support or challenge a claim. |
| Source | The record or publication where information comes from. |
| Independent evidence | Evidence not merely repeating the same underlying record. |
| Citation | Information identifying a source; it still needs to be checked. |
| Permission | What the applicable authority or rule allows in a specific setting. |
| Disclosure | An accurate account of assistance, following applicable requirements. |
| Attribution | Credit identifying a contributor or source. |
| Privacy | Concern for people's information and its use; a prompt alone does not protect it. |
| Algorithm | A sequence of steps for a task. |
| Pseudocode | Human-readable steps resembling code, without requiring execution. |
| Boundary case | An input at a limit, such as exactly 5 when checking “at least 5.” |
| Mean | Sum divided by the number of values, for a nonempty numerical list. |
| Transfer | Applying a skill to a different example. |
| Scenario | A possible situation built from assumptions, not a certain prediction. |
| Principle | A proposed value to guide choices; distinct from law or an implemented safeguard. |
