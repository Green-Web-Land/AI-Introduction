# Educator and supporter guide

[Course home](README.md)

## Before teaching

Read the full lesson and answers first. This course is intended for high-school learners, approximately 13–18; suitability has not been tested with learners. Adapt reading, mathematics and pace to the group. No learner must create an account, use AI, disclose a personal experience or share work publicly. Provide paper, spoken or typed responses as appropriate. Do not infer disability or misconduct from a learner's response.

The policy cards are wholly invented. State the actual rules for any school activity separately, including permitted assistance and acknowledgement. If actual rules are uncertain, resolve them before optional live-tool use. This course does not require such use or establish provider eligibility, school consent or privacy arrangements.

## Facilitation

Model one reasoning step, let learners attempt the next and invite an explanation. Ask “Which step or source supports that?” rather than rewarding a confident tone. Allow time to correct an error without embarrassment. Explain that our assistant replies are authored fiction, not a comparison of commercial products.

Lesson 5 uses the original 12-of-20 pilot count; its transfer introduces a correction to 10 of 20. Lesson 6 explicitly asks learners to revise when that correction is used. Neither version measures learning. Keep the version labels visible.

Use the text equivalents when images are inconvenient. Read >= as “greater than or equal to.” The code is a paper trace; no execution or installation is needed. Use diagrams as prompts for discussion rather than substitutes for the explanations. Accessibility accommodations should respond to learners; this package has no formal accessibility certification.

## Portfolio feedback

| Task | Look for | If not yet clear |
|---|---|---|
| Permission | Correct decision under the exact fictional rule; asks when unclear | Compare the allowed use with the requested use |
| Equation | Identifies the first incorrect step, repairs it and substitutes | Revisit multiplying both bracketed terms |
| Source | Reports preference counts and retains the measurement limit | Identify what was and was not measured |
| Code | Includes equality and shows running counts | Trace one value at a time, especially 5 |
| Privacy | Uses invented material without disguised private details | Replace the scenario rather than sanitising a real message |
| Disclosure | Describes actual help without invented claims | Compare each sentence against the supplied record |

Feedback can be “explained,” “partly explained” or “revisit.” This is a course discussion aid, not a diagnostic test, misconduct detector, validated grading rubric or credential. Do not assign a student a label from these categories.

## Concerns and future discussion

If a learner describes harmful sharing, listen without asking for public details. Use the school's appropriate safeguarding/support process; do not ask them to recreate or circulate harmful material. Respect a learner's choice to use the offline activity.

For Lesson 10, separate hopes from evidence. Ask what assumptions could change and what observable work would show understanding. Discuss access and support without promising equal results from equal effort. The linked learning guidance supports task-specific reflection; it does not prove this course improves outcomes.

## Review before reuse

Check local rules and any external references again when adapting. Keep fictional labels, answer reasoning, source limitations and [reuse notices](LICENSE.md). Changes introducing accounts, submissions, tracking or live AI require their own design and privacy review; they are not features of these static lessons.
