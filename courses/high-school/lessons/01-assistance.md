# 1. AI assistance and responsibility

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

## Objective

Distinguish useful assistance from evidence that an answer is correct.

## Explanation

AI is a broad name for systems that perform tasks such as recognising patterns or generating suggestions. Generative AI can produce text, pictures or code. A fluent explanation can still contain an error; treat it as something to examine, not a teacher's verified answer. [Background sources](../SOURCES.md) explain these limited technical claims.

Our purpose is to learn to use AI well—and remain able to think, choose and act for yourself. You do not need an AI account for this course. All assistant replies below are fictional teaching examples written for this course, not outputs measured from a product.

Use three separate questions: Am I allowed to use this help? Is the claim supported? Can I explain my own reasoning? A “yes” to one does not settle the others.

## Worked example

Mina is practising vocabulary. A fictional assistant suggests a definition and an example sentence. Mina compares the definition with the teacher's supplied notes and writes a new sentence. That is a way to examine assistance. Copying an answer she cannot explain would not demonstrate the skill being practised.

## Practice

Label each statement as a possible use, a verification step, or an unsupported promise.

A. “Suggest three practice questions.”
B. “Compare the explanation with the supplied textbook passage.”
C. “Every answer is correct because it sounds confident.”
D. “Explain why your own solution fits the question.”

Then identify which statement tells you whether AI is permitted on a particular assignment.

## Answer and reasoning

Try the practice before reading this section.

A is a possible use, subject to permission. B checks evidence. C is an unsupported promise. D checks your understanding. None establishes assignment permission: read the actual instructions or ask the teacher. B can reveal disagreement but still requires you to inspect the relevant passage carefully.

## Transfer task

A fictional assistant offers a history date. Write two things you would need before using it in assessed work. Possible answer: permission for that use and a relevant source supporting the date; also be ready to explain and acknowledge the assistance as required. Repeating the same question to the assistant is not independent evidence.
