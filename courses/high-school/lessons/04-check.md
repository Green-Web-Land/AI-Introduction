# 4. Check and repair an explanation

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

## Objective

Locate a specific error, correct it and test the correction.

## Explanation

Check the steps, not just whether the final answer looks familiar. A useful review names where the reasoning changes incorrectly, shows the corrected step and tests the result against the original task. Confidence and a polished layout are not mathematical evidence.

Use an independent method when possible: substitution checks an equation solution against the original equation. It does not establish that every statement in a longer explanation is right.

## Worked example

Fictional assistant reply:

“3(x + 2) = 21, so 3x + 2 = 21. Therefore x = 19/3.”

The first expansion is wrong: the 3 multiplies both terms inside the brackets. Correct expansion: 3x + 6 = 21. Subtract 6 and divide by 3 to obtain x = 5. The proposed 19/3 gives 3(19/3 + 2) = 25, not 21.

## Practice

Repair this new fictional reply:

“2(y + 4) = 22. Expanding gives 2y + 4 = 22, so y = 9.”

Write the first incorrect step, the corrected expansion, the solution and a substitution check. Do not just write “AI was wrong.”

## Answer and reasoning

Try the practice before reading this section.

The expansion omitted multiplication of 4 by 2. Correct: 2y + 8 = 22; then 2y = 14 and y = 7. Check: 2(7 + 4) = 22. The proposed 9 would give 26. This identifies the error and tests the replacement.

## Transfer task

Solve 4(z + 1) = 28 without looking at the worked examples. Then explain the distributive step in words. Answer: 4z + 4 = 28; z = 6; 4(6 + 1) = 28. If your numerical answer is right but you cannot explain the step, practise the explanation before moving on.
