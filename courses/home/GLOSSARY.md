# Glossary

[Course home](README.md)

| Term | Meaning here |
|---|---|
| AI | Systems used for tasks such as pattern recognition or generating suggestions. |
| Generative AI | AI producing content; its output still needs checking. |
| Prompt | Input or instructions, not an implemented privacy or permission control. |
| Constraint | A stated limit, such as available time or materials. |
| Fictional | Invented for practice, not a record of actual people or events. |
| Estimate | A proposed amount or duration that may need revision. |
| Evidence | Relevant information supporting or challenging a claim. |
| Privacy | Concern for personal information and its use; names are not the only identifiers. |
| Draft | Prepared material, distinct from sending or applying it. |
| Permission | Authority for a particular use or action in its context. |
| Verification | Checking against relevant evidence or actual results. |
| Scenario | A conditional possibility, not a certain forecast. |
| Transfer task | A new example where you apply the skill yourself. |
