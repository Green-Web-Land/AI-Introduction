# 7. Keep your own creative choices

[Course home](../README.md) · [Curriculum](../CURRICULUM.md)

## Objective

Use a suggestion as a starting point you can revise.

## Explanation

Creative assistance need not replace your taste or effort. Ask for options, choose one and change it. Fiction can be invented; a factual claim inside a story still needs checking if you present it as true.

No real person, private photograph or copyrighted character is needed for the supplied activity. Other people's material has its own rights; the course licence does not give rights to everything you might ask a tool to generate.

## Worked example

Original fictional prompt: “Suggest a first line about a tiny paper town, without named existing characters.”

Supplied suggestion: “The paper town woke when a folded door began to sing.”
A learner changes it to: “At dawn, a pencilled path appeared between two paper houses.” Neither version is a factual claim. The learner chooses which mood to develop.

## Practice

Write two new sentences continuing either opening, or draw a scene. Name one change you made and why. No artistic skill score or public sharing is required.

## Answer and reasoning

Attempt the practice before reading this section.

Many answers work. A useful explanation connects a choice to the intended effect: a quieter mood, a surprise or a clearer setting. Copying the example is allowed for practice, but it does not show which creative decision you made. Add or change something you can explain.

## Transfer task

A suggestion says a real historical event occurred on a particular date. If you want a factual story, mark that detail for source checking instead of accepting it because the prose is vivid. If you invent an alternate world, label it fictional rather than present the date as history.
