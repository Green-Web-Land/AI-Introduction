# Developer and adaptation guide

[Course home](README.md)

Ten Markdown lessons, eight supporting documents and five SVG/PNG pairs. No code execution, API connection, learner account, tracking or submission feature is included. GitHub or another host has its own practices; static content is not proof of no host collection.

Preserve lesson identifiers, relative links and images. SVGs are editable originals; PNGs are display versions. Retain alt text and [text equivalents](ASSET-SOURCES.md). Test reading order, contrast, zoom and assistive-technology behaviour in your own integration; no formal accessibility conformance is claimed.

Keep invented prices, fictional product card, example durations and household details labelled. Do not transform them into real specifications, medical routines or market claims. Preserve the separation between preparation and action. An interface that connects devices, buys items or sends messages is a separate feature requiring its own permission, technical and privacy assessment.
