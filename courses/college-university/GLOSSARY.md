# Glossary

[Course home](README.md)

| Term | Meaning in this course |
|---|---|
| Generative AI | A system producing content such as text, images or code; output still needs examination. |
| Prompt | Input or instructions to a system, not a guarantee of its behaviour. |
| Research question | A question specifying what you want to investigate and what evidence is relevant. |
| Search term | A word or phrase used to look for information; it is not a source. |
| Citation | Information identifying a source; check both its identity and the attached claim. |
| Primary record | The underlying record for a claim, rather than a repetition of it. |
| Synthesis | An explanation connecting evidence to a question, including differences and limits. |
| Outcome | What was measured or examined. |
| Sample | The people or observations included in a study or dataset. |
| Self-selection | Participants choosing a group or condition, as in our fictional pilot. |
| Association | A relationship between variables; it alone does not establish cause. |
| Causal claim | A claim that one thing produces an effect on another. |
| Mean | Sum divided by the number of values in a nonempty numerical list. |
| Median | The middle value in a sorted list, or the average of the two middle values for an even count. |
| Denominator | The quantity you divide by; it must be specified for a percentage comparison. |
| Missing | No observed value represented in our example; distinct from a recorded zero. |
| Pseudocode | Human-readable procedural steps used here without execution. |
| Method record | Inputs, versions and steps that allow a reader to inspect what was done. |
| Disclosure | An accurate account of assistance under applicable requirements. |
| Scenario | A possible future built from stated assumptions, not a certain prediction. |
