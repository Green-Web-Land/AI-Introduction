# Word help

[Home](README.md) · [Curriculum](CURRICULUM.md)

| Word | Meaning here |
|---|---|
| AI | Computer systems built for tasks such as recognising patterns or generating answers. |
| Application | The software you use; it may connect an AI model to other tools. |
| Model | A part of an AI system developed to produce outputs from inputs, often using patterns learned from examples. |
| Prompt | The request or information you give an AI tool. |
| Output | What a system produces, such as text or a picture. |
| Fact | Something that can be checked; a claim is not automatically a fact. |
| Evidence | Information that helps us check a claim. |
| Fictional | Invented for a story or example. |
| Prediction | An estimate about what might happen, which may be wrong. |
| Scenario | One possible story about the future, with assumptions. |
| Assumption | Something treated as true for an exercise that may need checking in real life. |
| Privacy | Having appropriate protection and choices about personal information. |
| Permission | Being allowed to do a particular thing; ability alone does not give permission. |
| Bias | A pattern that can make results unfair or systematically unbalanced. |
| Principle | A guiding idea about what ought to happen. |
| Verify | Check using suitable facts, evidence or a reliable method. |

Try explaining one word with your own made-up example. Ask a trusted adult if a word remains confusing.
