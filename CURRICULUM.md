# Curriculum — first edition

[Home](README.md)

Audience: adult beginners. Language: plain English. Format: self-study, readable on GitHub and reusable in an application. No AI account is required for the core exercises.

Each lesson contains one main learning objective, a short explanation, a worked example, a practice task and a way to check the learner's answer. Suggested reading/practice times are editorial estimates, not measured completion times.

Plan roughly 10–15 minutes per lesson, with extra practice if useful; allow 20–30 minutes for the Prediction worksheet. A glossary, answer guidance, source notes and developer integration guide complete the first edition. All nine lesson files are linked below or in the table above.

Read the table in its displayed order. Stable identifiers do not dictate reading order: AIE-09 is the new foundation chapter after What is AI? Allow 20–30 minutes for its examples and exercise. The first edition now contains nine topics.

## Teaching boundaries

Begin with ordinary tasks and synthetic information. Explain terms before using them. Clearly separate what an example demonstrates from what any particular AI product can do. An output that looks polished is not evidence of accuracy. Introduce verification as part of the task, not as a warning added at the end.

For “Never Do with AI,” cover sharing secrets or other people's information without permission; treating an unverified answer as sufficient for a consequential decision; granting uncontrolled access; impersonating people or fabricating evidence; and approving actions the user does not understand. Legitimate learning in sensitive subjects remains possible with appropriate boundaries.

The first edition teaches general literacy. It will not promise professional qualifications, guaranteed results, universal tool capabilities or a substitute for expert judgment. Accessibility starts with meaningful headings, text-based examples, descriptive links and no required images or audio.
